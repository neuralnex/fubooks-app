# FUBOOKS Lottie assets

`cart-empty.json` and `order-success.json` are original, locally bundled FUBOOKS vector animations. They do not use paid or externally hosted LottieFiles assets, so there are no third-party animation fees, attribution requirements, or CDN dependencies.

They are rendered with `lottie-react-native`. `LottieIllustration` honors the device's Reduce Motion setting.
